# Jungle Learning Quest 🌿

Jungle Learning Quest is an interactive educational quiz game for students in Classes 6, 7 and 8.

## Features

- Three learning worlds: Mathematics, Science and Social Science
- Chapter-based quizzes with multiple-choice questions
- Scores, stars and coins for completed quizzes
- Unlockable character companions
- Player profile and progress tracking
- Progress saved in the browser using local storage
- Responsive layout for desktop and mobile screens

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Enter an explorer name, choose a class and start playing.

No installation or build step is required.

## Publish with GitHub Pages

1. Push these files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Notes

- Player progress is stored locally in the browser. It is not synchronized between devices or browsers.
- This project uses plain HTML, CSS and JavaScript.
