# LightLab - Explore the World of Light

An interactive, browser-based physics learning platform for exploring **Reflection, Refraction, Mirrors, Lenses, Ray Diagrams, Optical Illusions, and Optics Quizzes**. Built with clean HTML5, CSS3, and JavaScript Canvas APIs with zero build steps or external dependencies.

## Features

1. **Reflection & Refraction Simulator**
   - Adjust incident angle (0 to 85 degrees) and optical media (Air, Water, Crown Glass, Diamond).
   - Real-time calculation of reflected angle, refracted angle via Snell's Law, critical angle, and Total Internal Reflection (TIR).
2. **Mirrors & Lenses Ray Diagram Workbench**
   - Supports Convex Lens, Concave Lens, Concave Mirror, and Convex Mirror.
   - Live principal ray tracing with dynamic readouts for image distance, magnification, and image nature.
3. **Optical Illusions Studio**
   - Interactive demonstrations of the Muller-Lyer Illusion, Ebbinghaus Size Illusion, and Simultaneous Luminance Contrast with geometric overlay reveals.
4. **Adaptive Optics Quiz**
   - Conceptual and numerical questions with instant validation, score tracking, and step-by-step explanations.
