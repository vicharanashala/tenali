# Version 0.0
**Date:** 2026-07-06
**Focus:** UI theme updates, mascot integration, and initial animation attempt.

### Decisions Made:
* Implemented dynamic theme switching via button clicks.
* Added mascot components and decorative UI elements.
* Started work on `flyDiagonal` CSS keyframe animation for a floating broom.

### Challenges & Unresolved Issues:
* **Layering:** The broom is currently overlaying content instead of staying behind it.
* **Trajectory:** The animation path is not yet fully optimized; it is clipping at the edges.

### Next Steps:
* Debug the stacking context to ensure the broom stays strictly behind UI elements.
* Refine animation path and `overflow` settings to prevent clipping.
