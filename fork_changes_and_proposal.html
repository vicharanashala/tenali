Architectural Motivation

Why Was This Fork Created?

In early-childhood mathematics education, spoken interaction ("saying the number aloud") forms a vital neural bridge between visual symbols (numeral shapes) and conceptual quantity (counting objects). The original Tenali repository lacked accurate speech recognition for young children learning numbers.

1

The Problem with Web Speech API

Native browser speech (webkitSpeechRecognition) is trained predominantly on adult English. Children have higher pitch frequencies (F₀ > 300Hz), irregular cadence, and vocal elongation that adult models routinely drop or misinterpret as background noise.

2

Indian Accents & Homophones

Children across India pronounce numbers with distinct phonetic shifts: "tree" / "free" for 3, "won" / "van" for 1, "ait" for 8, or count in regional tongues (Hindi: ek, do, teen; Tamil: ondru, rendu, moonu; Telugu: okati, rendu, moodu). Generic adult speech engines reject these outright.

3

The Fine-Tuned Whisper Solution

I fine-tuned OpenAI's Whisper-Tiny model specifically on spoken Indian digits 1 to 10 (gradient-queen/whisper-tiny-indian-digits-final) and bundled quantized ONNX weights directly into the browser to eliminate server hosting dependencies.

Interactive Learning Loop: Tactile Numeral Tracing & Space Maze

Rather than passive multiple-choice quizzes, the fork builds a multi-sensory 3-stage mastery loop:

Stage 1: Tactile Tracing

Animated 3D cursor guides finger/mouse along real SVG paths with sample distance scoring (<55px) and auditory pitch feedback.

Stage 2: Echo Counting

Call-and-response rhythm: App prompts "Say One", child echoes into mic; target object turns glowing green with checkmark badge.

Stage 3: Space Rocket Launch

Child commands spacecraft from Pad 1 to Saturn (Pad 10) through jumbled cosmic stations by speaking or tapping station numbers.

Architectural Comparison

The 3 Deployment Strategies from the RFC

How we can run the custom fine-tuned Whisper model for Tenali users across different hosting setups:

Option 1: Recommended <120 ms

CTranslate2 Daemon on tenali.fun

Colocate a lightweight Python service (faster-whisper) on the existing Linux VPS alongside Node.js via systemd. Nginx proxies requests to 127.0.0.1:8000.

  • Speed: Sub-120ms latency on CPU
  • Cost: $0 additional cloud charges
  • RAM: Only ~150 MB (CTranslate2)
  • Security: Same-origin, no CORS/CSRF
Ideal when tenali.fun VPS has ~200MB spare RAM headroom.
Option 2: Cloud Container ~180 ms

Render / Railway Dedicated API

Deploy server.py in a pre-warmed Docker container on Render or Railway ($5–$7/mo). Vercel routes traffic through a reverse-proxy path.

  • Isolation: Zero load on tenali.fun VPS
  • Warm State: No cold starts on paid tier
  • Cost: ~$5/mo cloud subscription
  • Scale: Auto-scales with traffic
Ideal if the main web server must remain isolated from AI inference.
Option 3: Implemented Here 1.2s - 2.5s

100% In-Browser ONNX (Serverless)

Quantize model to INT8 ONNX and run directly inside client browser via Transformers.js v3 and WebAssembly inside a dedicated Web Worker.

  • Serverless: Runs on Vercel with 0 backend servers
  • Offline: Operates 100% without internet once cached
  • Privacy: Voice never leaves child's device
  • Consideration: 1–2s inference on mobile CPU
Currently active on tenali-one.vercel.app.
Technical Mastery

Key Engineering Breakthroughs in this Fork

Running Whisper client-side on Vercel required solving several non-trivial web runtime and bundler challenges:

✔ 1. Elimination of Vite IIFE Worker Bundling Crash Commit 4782d371

Vite automatically bundled worker scripts into IIFE format, converting CDN imports into undefined globals (ReferenceError: https___cdn_jsdelivr_net... is not defined). Fixed by serving client/public/whisper-worker.js as an unbundled static public ES module.

✔ 2. Merged Decoder ONNX Generation for Transformers.js v3 Commit 16721c4a

Transformers.js v3 Seq2Seq pipeline required decoder_model_merged.onnx. Resolved 404 network errors by merging decoder_model.onnx and decoder_with_past_model.onnx using Hugging Face Optimum.

✔ 3. Suppressed Stale "No Speech" Warnings During Transcription Commit 056d2513

Fixed UI glitch where stale error messages persisted while transcribing because condition checked only !isRecording. Updated to errorMessage && !isRecording && !isTranscribing, anchored auto-stop timers in refs, and cleared errors on recording stop.

✔ 4. Zero-Latency Warm Audio Stream & Real-time VU Visualizer Commit 3bc69fbf

Reused warm MediaStream and AudioContext to eliminate the 250ms hardware delay on every mic tap. Computes Root-Mean-Square (RMS) decibels in real-time to drive 4 animated sound wave bars, giving visual feedback and diagnosing muted mics.

✔ 5. Hybrid Speech Cascade: Native Interim + Neural Fallback Commit 3ca5ffbb

If browser native speech detects a number instantly, it emits immediately with 0 latency. If native speech drops or struggles with child accents, Whisper ONNX transcribes the audio chunk in the background as an accurate fallback.
