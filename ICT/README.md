# Balance It! — Chemical Equation Learning Lab

A responsive, interactive educational website about **balancing chemical equations**. Built with plain HTML, CSS and JavaScript, so it can be hosted for free with GitHub Pages.

## Features

- Introduction to balancing chemical equations and the law of conservation of mass.
- Interactive simulation with five sample reactions.
- Editable coefficients and live atom counters for reactants and products.
- Auto-balance and reset controls.
- Three-question knowledge check with instant feedback.
- Responsive layout for desktop, tablet and mobile.

## Project files

- `index.html` — page structure and content.
- `styles.css` — layout, colors, typography and responsive design.
- `script.js` — reaction data, simulation logic and quiz.
- `.gitignore` — common files to exclude from Git.

## Run it on your computer

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in a browser.

No installation, build command, or server is required. An internet connection is needed only for the optional Google Fonts used in the design; the site otherwise works offline.

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com/) and create a **new public repository**. For example, name it `balancing-chemical-equations`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md` and `.gitignore` to the repository's root (not inside another folder).
3. Open the repository's **Settings** tab.
4. Select **Pages** from the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. Wait a few minutes. GitHub will show the published website address in the Pages section. It will usually look like:
   `https://YOUR-USERNAME.github.io/balancing-chemical-equations/`

If you update the files later and push/commit the changes to `main`, GitHub Pages will publish the update automatically.

## Educational note

The sample reactions and their balanced coefficients are included as learning examples. The simulation checks atom counts for the selected reactions; it is not a general-purpose chemical equation solver.
