# Evaporation – Interactive Science Project

A responsive educational website that introduces evaporation through explanations, everyday examples, a simple interactive model, and a five-question quiz.

## Features

- Definition and key characteristics of evaporation
- Factors affecting the rate: temperature, wind speed, surface area, and humidity
- Everyday examples
- Interactive relative-rate explorer
- Five-question quiz with instant feedback and score
- Responsive layout for mobile, tablet, and desktop

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No build tools, package manager, or server are required.

## Publish with GitHub Pages

1. Create a new repository on GitHub (for example, `evaporation-project`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your public website link will appear in the Pages section.

## Note about the simulation

The interactive explorer uses a simplified illustrative score to demonstrate how the factors can influence evaporation. It is not a measured scientific model and should not be used to predict real evaporation rates.

## Learning objectives

After exploring this project, learners should be able to:
- Define evaporation.
- Identify its main characteristics.
- Explain four factors that affect its rate.
- Relate evaporation to everyday observations.
