# Can Mathematics Predict Luck? – Exploring Probability 🎲

An interactive, visual, and beginner-friendly mathematics teaching website created for **Class 8–10 students** to learn **Probability** by exploring, playing games, running live simulations, and solving problems.

## ✨ Features Included
1. **Interactive Homepage** – Playable coin, die, and probability spinner right on the hero card.
2. **The Mystery of Chance** – Prediction cards that let students guess before revealing the mathematical explanation.
3. **Learn the Mathematics** – Step-by-step concept cards, an interactive **0-to-1 Probability Scale**, the Golden Probability Formula, and worked examples (Coins, Dice, Coloured Balls).
4. **Interactive Coin Toss Lab** – Animated 3D coin flip, Toss 1 / 10 / 100 buttons, experimental probability readouts, and a live bar graph with a 50% theoretical reference line.
5. **Interactive Dice Lab** – Animated rolling die, Roll 1 / 10 / 60 buttons, live frequency table, and real-time bar graph comparing results to 1/6 (16.7%).
6. **Probability Challenge – Predict Before You Play** – 6 interactive prediction scenarios with instant explanations.
7. **Practice Quiz** – 10 Easy & Medium questions with live progress bar, instant feedback, final score, answer review, and restart option.
8. **What Did We Discover? + Mystery Bag Detective** – Key takeaways plus a hidden-bag probability detective game.

## 📁 Project Files
- `index.html` – Website structure and content for all 8 sections.
- `styles.css` – Colourful, modern, mobile-responsive styling and animations.
- `script.js` – Interactive simulations, live graphs, prediction game, and quiz logic (pure Vanilla JS, no build step needed).

## 🚀 How to Run Locally
Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Safari, or Firefox). No installation or server is required!

## 🌐 How to Publish Free on GitHub Pages
1. Create a new **Public** repository on GitHub (for example, `exploring-probability`).
2. Click **Add file → Upload files**.
3. Upload `index.html`, `styles.css`, `script.js`, and `README.md` directly into the root of the repository and click **Commit changes**.
4. Go to **Settings → Pages**.
5. Under **Build and deployment → Branch**, select **`main`** and folder **`/ (root)`**, then click **Save**.
6. Wait 1–2 minutes and refresh the page to get your live website URL!

## ✏️ How to Customize
- **Add Your Name:** Open `index.html`, search for `[Your Name / Class]` in the footer, and replace it with your own details.
- **Edit Questions:** Open `script.js` and edit the `mysteryQuestions`, `challenges`, or `quizQuestions` arrays.
