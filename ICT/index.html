Section 2 • Core Ideas

Learn the Concepts Simply

Clear visual building blocks — understand what every symbol means so formulas make instant sense.

SEQUENCE (Ordered List)

Numbers lined up in order with commas

2, 4, 6, 8, 10

Each item is called a term (a1, a2, a3, …). We care about the pattern and finding any specific term like the 20th term.

VS
SERIES (Running Sum)

Adding the terms up with plus signs

2+ 4+ 6+ 8+ 10= 30

A series is the sum of a sequence, written as Sn (or with sigma Σ). We care about the total!

🪜
Constant Addition

Arithmetic Progression (AP)

Every term changes by adding the same number, called the common difference (d).

a = 1st term d = a₂ − a₁ n = term position
n-th Term Formula
an = a + (n − 1)d
Sum of First n Terms
Sn = (n / 2) [ 2a + (n − 1)d ]
or simply: Sn = (n / 2)(a + l), where l = last term
🚀
Constant Multiplication

Geometric Progression (GP)

Every term changes by multiplying by the same factor, called the common ratio (r).

a = 1st term r = a₂ ÷ a₁ n = term position
n-th Term Formula
an = a · rn−1
Finite Sum (when r ≠ 1)
Sn = a(rn − 1) / (r − 1)
Infinite Sum when |r| < 1: S∞ = a / (1 − r)
🌻
Famous Patterns

Special Sequences

Not every pattern is purely AP or GP! Here are three iconic patterns you see everywhere:

🌀 Fibonacci Sequence 1, 1, 2, 3, 5, 8, 13, 21… Rule: Add the previous two terms (Fn = Fn−1 + Fn−2).
⬛ Square Numbers 1, 4, 9, 16, 25, 36… Rule: an = n² (area of an n × n square grid).
🔺 Triangular Numbers 1, 3, 6, 10, 15, 21… Rule: 1 + 2 + … + n = n(n + 1) / 2 (bowling pin rows!).

📝 Step-by-Step Worked Examples (Zero Steps Skipped!)

Problem: Consider the AP: 5, 9, 13, 17, … Find its 10th term (a10) and the sum of the first 10 terms (S10).
5+4 9+4 13+4 17… a10 = ?
  1. Step 1 – Identify a, d, and n: First term a = 5. Common difference d = 9 − 5 = 4. Position n = 10.
  2. Step 2 – Find the 10th term using an = a + (n − 1)d:
    a10 = 5 + (10 − 1) × 4 = 5 + 9 × 4 = 5 + 36 = 41.
  3. Step 3 – Find the sum S10 using Sn = (n / 2)(a + l):
    S10 = (10 / 2) × (5 + 41) = 5 × 46 = 230.
  4. Quick Check: Using (n / 2)[2a + (n − 1)d] = 5 × [10 + 36] = 5 × 46 = 230 ✓
Problem: Consider the GP: 3, 6, 12, 24, … Find its 6th term (a6) and the sum of the first 6 terms (S6).
3×2 6×2 12×2 24… a6 = ?
  1. Step 1 – Identify a, r, and n: First term a = 3. Common ratio r = 6 ÷ 3 = 2. Position n = 6.
  2. Step 2 – Find the 6th term using an = a · rn−1:
    a6 = 3 × 26−1 = 3 × 25 = 3 × 32 = 96.
  3. Step 3 – Find the sum S6 using Sn = a(rn − 1) / (r − 1):
    S6 = 3 × (26 − 1) / (2 − 1) = 3 × (64 − 1) / 1 = 3 × 63 = 189.
  4. Quick Check: 3 + 6 + 12 + 24 + 48 + 96 = 189 ✓
Problem: Find the sum to infinity of the shrinking series: 16 + 8 + 4 + 2 + 1 + …
16×0.5 8×0.5 4×0.5 2… S∞ = ?
  1. Step 1 – Check if it converges: First term a = 16, common ratio r = 8 ÷ 16 = 0.5. Since |r| = 0.5 < 1, the terms shrink toward 0, so an exact finite sum exists!
  2. Step 2 – Apply S∞ = a / (1 − r):
    S∞ = 16 / (1 − 0.5) = 16 / 0.5.
  3. Step 3 – Divide cleanly: Dividing by 0.5 is the same as multiplying by 2 → 16 × 2 = 32!
  4. Intuition: No matter how many terms you add (16 + 8 = 24, + 4 = 28, + 2 = 30, + 1 = 31, + 0.5 = 31.5…), the total closes in on 32 and never crosses it.
Problem: A school auditorium has 20 seats in Row 1, 24 seats in Row 2, 28 seats in Row 3, and so on. How many total seats are in the first 12 rows?
  1. Step 1 – Spot the pattern: Each row adds 4 seats (24 − 20 = 4), so this is an AP with a = 20, d = 4, and n = 12.
  2. Step 2 – Choose the Sum Formula: Sn = (n / 2)[ 2a + (n − 1)d ].
  3. Step 3 – Substitute carefully:
    S12 = (12 / 2) × [ 2(20) + (12 − 1) × 4 ]
    S12 = 6 × [ 40 + 11 × 4 ] = 6 × [ 40 + 44 ] = 6 × 84.
  4. Step 4 – Final Answer: 6 × 84 = 504 seats in total!

Section 6 • 30-Second Review

Quick Formula Cheat Sheet

Everything you need to remember before a class test — neatly organized on four clean cards.

01 • AP

Arithmetic Progression

  • Rule: Add constant d = a₂ − a₁
  • n-th Term: an = a + (n − 1)d
  • Sum Sn: (n / 2)[2a + (n − 1)d]
  • Shortcut: Sn = (n / 2)(a + l)
02 • GP

Geometric Progression

  • Rule: Multiply by constant r = a₂ ÷ a₁
  • n-th Term: an = a · rn−1
  • Sum (r ≠ 1): Sn = a(rn − 1) / (r − 1)
  • Infinite (|r| < 1): S∞ = a / (1 − r)
03 • SPECIAL

Famous Sums & Patterns

  • 1 + 2 + … + n = n(n + 1) / 2
  • 1² + 2² + … + n² = n(n + 1)(2n + 1) / 6
  • Odd sum (1+3+…): First n odds = n²
  • Fibonacci: Fn = Fn−1 + Fn−2
04 • TIPS

Golden Exam Takeaways

  • Sequence has commas; Series adds them up.
  • Check a₂ − a₁ = a₃ − a₂ to prove AP.
  • Check a₂ / a₁ = a₃ / a₂ to prove GP.
  • Exponential (GP) always beats Linear (AP) eventually when r > 1!
